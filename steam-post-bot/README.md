# Steam Post Bot — внутренний бот-редактор для канала

Бот для вас и ваших администраторов: присылаете Steam-ссылку (и, при желании,
текст про раздачу) — бот сам получает данные и баннер игры из Steam, отдаёт
текст на редактуру Gemini, показывает предпросмотр с кнопками и публикует
готовый пост в канал по вашему подтверждению.

Работает **только через обычный Telegram Bot API** — без Telethon и без
пользовательского Telegram-аккаунта, как и было нужно.

## Как это устроено

```
Админ → Telegram Bot
           │ (текст / Steam-ссылка / текст+ссылка)
           ▼
      steam.py       — извлекает App ID из ссылки, получает проверенные
                        данные из Steam Store API (название, описание,
                        разработчик, дата релиза, изображение)
           ▼
      image.py        — скачивает официальный баннер и приводит его к
                         1920×1080 без искажений (cover + центральная обрезка)
           ▼
      gemini.py        — редактирует ТОЛЬКО текст, на основе уже проверенных
                          данных; ссылку и App ID не придумывает
           ▼
      publisher.py      — программно добавляет кликabельный заголовок со
                           Steam-ссылкой, собирает финальный пост
           ▼
      предпросмотр админу: 🟢 Опубликовать / ✏️ Редактировать /
                            🔄 Создать заново / ❌ Отменить
           ▼
      публикация в канал (или сразу, если AUTO_PUBLISH=true)
```

## Структура проекта

```
steam-post-bot/
├── main.py            # точка входа, регистрация обработчиков
├── config.py           # загрузка .env
├── logger_setup.py      # логирование в файл
├── database.py           # SQLite: администраторы и посты
├── telegram_bot.py        # все команды и обработчики сообщений/кнопок
├── gemini.py               # вызов Gemini API (только редактура текста)
├── steam.py                 # Steam App ID + Steam Store API
├── image.py                  # скачивание и обработка баннера 1920x1080
├── publisher.py                # сборка финального поста и отправка
├── prompts/
│   └── post_editor.txt          # промпт Gemini — правьте без изменения кода
├── systemd/
│   └── steam-post-bot.service
├── data/                          # тут будет SQLite база
├── logs/                           # тут будет лог-файл
├── tmp/                             # тут будут временные обработанные баннеры
├── requirements.txt
├── .env.example
└── .gitignore
```

## Локальный запуск (Windows/любая ОС) — для первого теста

### 1. Установка Python

Скачайте и установите Python 3.11+ с https://python.org (при установке на
Windows отметьте галочку "Add Python to PATH").

### 2. Создание виртуального окружения

```powershell
cd steam-post-bot
python -m venv venv
venv\Scripts\activate
```

(на Linux/macOS: `python3 -m venv venv && source venv/bin/activate`)

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Создание .env

```bash
copy .env.example .env
```
(на Linux/macOS: `cp .env.example .env`)

### 5. Получение Telegram Bot Token

1. Откройте `@BotFather` в Telegram.
2. `/newbot`, задайте имя и username.
3. Скопируйте токен в `TELEGRAM_BOT_TOKEN`.

### 6. Ваш OWNER_ID и ADMIN_IDS

Напишите любое сообщение боту `@userinfobot` — он покажет ваш числовой ID.
Вставьте его в `OWNER_ID`. При желании добавьте ID других администраторов
через запятую в `ADMIN_IDS` (можно оставить пустым и добавить их позже
командой `/addadmin`).

### 7. ID канала

Перешлите любое сообщение из вашего канала боту `@userinfobot` (или
`@getidsbot`) — он покажет ID вида `-1001234567890`. Вставьте его в
`TELEGRAM_CHANNEL_ID`.

### 8. Добавление бота администратором канала

В настройках канала → "Администраторы" → добавить вашего нового бота, с
правом **публикации сообщений** (Post Messages). Без этого бот не сможет
писать в канал.

### 9. Настройка Gemini API

1. https://aistudio.google.com/apikey → создайте ключ.
2. Вставьте его в `GEMINI_API_KEY`.
3. Проверьте актуальное название модели и при необходимости поправьте
   `GEMINI_MODEL` (по умолчанию `gemini-2.0-flash`).

### 10. Запуск

```bash
python main.py
```

## Как протестировать

1. Оставьте `AUTO_PUBLISH=false` (по умолчанию) — так пост не уйдёт в канал
   без вашего подтверждения.
2. Напишите боту (от лица админа, добавленного в `ADMIN_IDS`/`OWNER_ID`)
   что-то вроде:
   ```
   https://store.steampowered.com/app/738520/Breathedge/
   Раздача до 10 августа, при активации +1 к значку коллекционера Steam
   ```
3. Бот получит данные из Steam, скачает и обработает баннер, отправит текст
   в Gemini и покажет предпросмотр с кнопками.
4. Проверьте текст, при необходимости нажмите ✏️ Редактировать и пришлите
   правку текстом, либо 🔄 Создать заново.
5. Нажмите 🟢 Опубликовать — пост уйдёт в канал.
6. Когда всё устраивает, можно поставить `AUTO_PUBLISH=true`, если хотите,
   чтобы посты публиковались сразу без подтверждения (не рекомендуется,
   пока не протестируете формат постов).

## Перенос на Oracle Cloud (Ubuntu VM)

### Установка Python и загрузка проекта

```bash
sudo apt update && sudo apt install -y python3-venv python3-pip
# скопируйте папку steam-post-bot на сервер (scp/git clone) и перейдите в неё
cd steam-post-bot
```

### Создание .env и установка зависимостей

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните так же, как описано выше
```

### Запуск (проверка вручную)

```bash
python main.py
```

Остановите (Ctrl+C), убедившись, что бот стартует без ошибок.

### Настройка systemd (автозапуск после перезагрузки)

1. Откройте `systemd/steam-post-bot.service`, замените `YOUR_LINUX_USER` и
   пути на реальные.
2. Установите:

```bash
sudo cp systemd/steam-post-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable steam-post-bot
sudo systemctl start steam-post-bot
```

3. Проверка статуса:

```bash
sudo systemctl status steam-post-bot
```

### Просмотр логов

```bash
tail -f logs/bot.log
```

Или, если бот под systemd:

```bash
sudo journalctl -u steam-post-bot -f
```

## Команды бота

- `/start`, `/help` — приветствие и инструкция
- `/admins` — список администраторов бота
- `/cancel` — сбросить текущий диалог/черновик
- `/addadmin <id>`, `/removeadmin <id>` — только для владельца (`OWNER_ID`)

## Важные особенности реализации

- **Steam — единственный источник истины.** App ID определяется программно
  через regex по ссылке, а не Gemini. Название игры, ссылка, разработчик,
  дата релиза — всё берётся из Steam Store API (`store.steampowered.com/api/appdetails`),
  публичного и не требующего ключа.
- **Баннер — только официальный Steam artwork.** Бот скачивает
  `background_raw`/`header_image`/`capsule` (что доступно) и масштабирует до
  1920×1080 без искажения пропорций (Pillow, `ImageOps.fit` — заполнение
  кадра с аккуратной центральной обрезкой лишнего, без водяных знаков).
  Изображение, присланное админом вместе с сообщением, не используется в
  качестве баннера — это осознанное решение в пользу официального
  Steam-артворка, как и было указано в требованиях.
- **Ссылка добавляется программно**, а не Gemini: `publisher.py` берёт
  проверенный `steam_url` и оборачивает название игры в HTML-ссылку. Gemini
  видит инструкцию не создавать и не изменять URL.
- Если Gemini или Steam временно недоступны — черновик остаётся в SQLite
  (`status=draft`/`preview`), ничего не теряется; админ получает понятное
  сообщение об ошибке.
- Диалоговое состояние ("жду ссылку" / "жду правку") хранится в памяти
  процесса — после перезапуска бота достаточно отправить материал заново;
  сами черновики в базе не пропадают.
