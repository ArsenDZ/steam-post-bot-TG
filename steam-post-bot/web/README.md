# Steam Post Bot — Web Frontend

Фронтенд для веб-интерфейса генератора постов.

## Развёртывание на Vercel

1. Загрузи папку `web/` на GitHub
2. Подключи её на Vercel
3. Добавь переменную окружения `NEXT_PUBLIC_API_URL` (URL твоего API)
4. Vercel автоматически соберёт и развернёт

## Локальный запуск

```bash
cd web
npm install
npm run dev
```

Откроешь http://localhost:3000
